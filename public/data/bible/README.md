# Licensed Korean Bible data

The JSON files in this directory are generated locally from the Korean Bible Society
website after obtaining permission for BibleOn. Run `npm run data:kbs-bible` to create
the corpus.

The generated text is excluded from Git. Do not redistribute or publish the raw corpus
outside the scope of the written permission from the Korean Bible Society. Confirm that
the final agreement covers app display, server storage, search/RAG indexing, embeddings,
backups, and production delivery before release.

Source: https://www.bskorea.or.kr/bible/korbibReadpage.php
